LiteMd 原型体验

依据 PRD v0.3 / 技术方案 v0.2。左侧是模拟桌面，可直接操作；这里用来切换场景、模拟外部事件。

平台与系统外观

应用主题默认「跟随系统」，可在 LiteMd 设置 › 外观 中单独指定。

启动场景

外部事件（作用于当前文档窗口）

当前窗口：无

原文保真演示

在所见即所得中改一处再保存（或等自动保存），差异里只会出现被改动的块；其余块逐字节保持原文。

快捷键（macOS 为 ⌘，Windows 为 Ctrl）

预览 / 所见即所得 / 源码 / 分屏⌘1–4 预览 ⇄ 上次的编辑模式⌘E 查找 / 替换⌘F / ⌥⌘F 大纲⇧⌘O 保存⌘S 新建 / 打开⌘N / ⌘O 字号放大 / 缩小 / 还原⌘+ ⌘- ⌘0 加粗 / 斜体 / 链接⌘B ⌘I ⌘K

浏览器会占用部分组合键（如 ⌘N、⌘W、⌘1–4），按不出时请用菜单或状态栏。原型中 ⌥ 加数字也可切换模式。

原型说明

· 文件、磁盘、系统对话框均为模拟；可把电脑上的真实 .md 文件拖到启动窗口或文档窗口标题栏上打开。
· 公式和 Mermaid 用预先画好的示例代替真实渲染引擎；其他内容由原型内置的简化解析器渲染。
· 界面只做了简体中文；English 界面未在原型中体现。

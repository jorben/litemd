# 把注意力留给内容

一个文件，一个窗口。轻量便捷，用完即走。

## 只想读一份 Markdown

收到一份方案、打开项目说明、翻看 AI 生成的报告——有时，我们只需要一个安静的窗口。

> 不用先建立知识库。文件在哪里，就从哪里打开。

## 看得清楚，也改得顺手

- **预览**：专心阅读，避免误改。
- **所见即所得**：直接修改眼前的文字。
- **源码与分屏**：需要时，回到 Markdown 本身。
